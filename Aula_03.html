O que é Estatística Descritiva?

Conceito

"Estatística descritiva é a arte de transformar uma montanha de números em uma história que humanos conseguem entender."

— Hadley Wickham, criador do tidyverse (R)
📋

O que ela faz

  • Resume grandes volumes de dados
  • Identifica padrões e anomalias
  • Descreve sem fazer inferências
  • Prepara o terreno para modelagem
🔬

Estatística Descritiva vs. Inferencial

  • Descritiva: resume o que já temos
  • Inferencial: generaliza para uma população
  • Descritiva é sempre o primeiro passo
💼

Aplicações em Negócios

  • Perfil do cliente (age, renda, frequência)
  • Desempenho de vendas por região
  • Análise de churn e retenção
  • Monitoramento de KPIs

Medidas de Tendência Central

Média, Mediana e Moda

Tendência Central
Média
x̄
Soma de todos os valores dividida pela quantidade. Sensível a outliers.
x̄ = Σxᵢ / n
Dados contínuos
Mediana
Md
Valor central após ordenar os dados. Robusta a outliers e distribuições assimétricas.
P₅₀ — valor do meio
Dados com outliers
Moda
Mo
Valor mais frequente. Única medida aplicável a dados categóricos.
argmax(freq(xᵢ))
Dados categóricos

⚠️ Quando usar cada uma?

Média — distribuições simétricas, sem outliers extremos (ex: altura de pessoas)

Mediana — renda, preço de imóveis, salários — sempre que houver valores extremos

Moda — produto mais vendido, cor favorita, cidade mais frequente

Assimetria e Curtose

Forma

◄

🔺

k > 3

Platicúrtica

Pico baixo, caudas leves
k < 3

📈 Por que isso importa em negócios?

Retornos financeiros são leptocúrticos — a normal subestima a chance de eventos extremos (crashes, ganhos excepcionais). Ignorar curtose foi um fator no colapso de 2008.

📐 Histograma — a ferramenta base

  • Divide os dados em intervalos (bins)
  • Mostra a frequência de cada intervalo
  • Revela a forma da distribuição
  • Número de bins: regra √n ou de Sturges

🔑 Regra de Sturges para bins

k = 1 + 3.322 × log₁₀(n)
onde n é o número de observações

Para n=1000: k ≈ 11 bins. Ajuste conforme necessário para clareza visual.

A Distribuição Normal

Normal
f(x) = (1/σ√2π) × e^[−(x−μ)²/2σ²]
Função densidade de probabilidade

✅ Propriedades fundamentais

  • Simétrica em torno da média
  • Média = Mediana = Moda
  • Totalmente definida por μ e σ
  • Regra 68-95-99.7 (empírica)
  • Assimetria = 0, Curtose = 3

🔍 Padronização — Z-score

Z = (x − μ) / σ

Transforma qualquer normal em N(0,1). Útil para comparar valores de distribuições diferentes e detectar outliers (|Z| > 3).

🌍 Por que ela é tão central?

O Teorema Central do Limite garante que a média de grandes amostras se aproxima da normal — independente da distribuição original.

⚠️ Correlação ≠ Causalidade

Sorvete vendido e afogamentos têm correlação positiva — ambos aumentam no verão. A variável de confusão é o calor. Sempre questione o mecanismo causal antes de agir.

Análise de Variáveis Categóricas

Categóricas

📊 Frequência absoluta e relativa

  • Frequência absoluta: contagem de cada categoria
  • Frequência relativa: proporção (%) de cada categoria
  • Frequência acumulada: soma progressiva — útil para análise de Pareto

📐 Análise de Pareto

Regra 80/20

80% dos resultados vêm de 20% das causas. Em dados: ordenar por frequência descrescente e calcular frequência acumulada revela quais categorias concentram o impacto.

20% dos clientes = 80% da receita 20% dos SKUs = 80% das vendas

🔢 Qui-quadrado de associação

Testa se duas variáveis categóricas são independentes ou associadas. Valor p < 0.05 indica associação estatisticamente significativa entre, por exemplo, gênero e preferência de produto.

Estatística Descritiva com Pandas

Python
import pandas as pd
import numpy as np

# Carregar dataset
df = pd.read_csv("vendas.csv")

# ── Visão geral ──
df.describe()          # count, mean, std, min, quartis, max
df.describe(include="all")  # inclui categóricas

# ── Medidas coluna por coluna ──
df["valor"].mean()     # média
df["valor"].median()   # mediana
df["valor"].mode()[0]  # moda
df["valor"].std()      # desvio padrão
df["valor"].var()      # variância
df["valor"].skew()     # assimetria
df["valor"].kurt()     # curtose

# ── Quartis e percentis ──
df["valor"].quantile([0.25, 0.5, 0.75])
df["valor"].quantile(0.95)  # P95

# ── Variáveis categóricas ──
df["categoria"].value_counts()
df["categoria"].value_counts(normalize=True)  # proporção
# ── Tabela de contingência ──
tab = pd.crosstab(
    df["genero"],
    df["categoria"],
    margins=True
)

# Proporções por linha
pd.crosstab(
    df["genero"],
    df["categoria"],
    normalize="index"
)

# ── Detecção de outliers (IQR) ──
Q1 = df["valor"].quantile(0.25)
Q3 = df["valor"].quantile(0.75)
IQR = Q3 - Q1

outliers = df[
    (df["valor"] < Q1 - 1.5 * IQR) |
    (df["valor"] > Q3 + 1.5 * IQR)
]
print(f"Outliers: {len(outliers)} ({len(outliers)/len(df)*100:.1f}%)")

# ── Z-score para outliers ──
df["z_score"] = (
    (df["valor"] - df["valor"].mean()) /
    df["valor"].std()
)
outliers_z = df[df["z_score"].abs() > 3]

Correlação com Python

Python
import pandas as pd
from scipy import stats

# ── Pearson ──
r_pearson, p_pearson = stats.pearsonr(
    df["preco"], df["valor"]
)
print(f"Pearson r = {r_pearson:.3f} (p = {p_pearson:.4f})")

# ── Spearman (mais robusto) ──
r_spear, p_spear = stats.spearmanr(
    df["preco"], df["valor"]
)
print(f"Spearman ρ = {r_spear:.3f} (p = {p_spear:.4f})")

# ── Matriz de correlação ──
corr_matrix = df.select_dtypes("number").corr()

# Correlação de Spearman para todas as colunas
corr_spear = df.select_dtypes("number").corr(
    method="spearman"
)

# Pares com correlação forte (|r| > 0.6)
mask = corr_matrix.abs() > 0.6
fortes = corr_matrix[mask].stack().reset_index()
fortes = fortes[fortes["level_0"] != fortes["level_1"]]
print(fortes)
# ── Qui-quadrado (categóricas) ──
from scipy.stats import chi2_contingency

tabela = pd.crosstab(
    df["genero"],
    df["categoria"]
)

chi2, p, dof, esperado = chi2_contingency(tabela)
print(f"χ² = {chi2:.2f}")
print(f"p-valor = {p:.4f}")

if p < 0.05:
    print("Associação significativa ✅")
else:
    print("Variáveis independentes ❌")

📌 Interpretando o p-valor

p < 0.05 → rejeita H₀ (há associação)
p > 0.05 → não rejeita H₀ (independentes)

O p-valor não mede a força da associação, apenas se ela é estatisticamente diferente de zero.

Gabarito — Parte 1: Carga e Medidas

Referência
import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt
from scipy import stats

# 1. Carregar
url = "https://raw.githubusercontent.com/dsrscientist/dataset1/master/heart.csv"
df = pd.read_csv(url)
print(df.describe(include="all"))
print(df.isnull().sum())

# 2. Medidas para as colunas numéricas
for col in ["age", "trestbps", "chol"]:
    media  = df[col].mean()
    mediana= df[col].median()
    std    = df[col].std()
    cv     = (std / media) * 100
    print(f"\n{col}:")
    print(f"  Média:   {media:.2f}")
    print(f"  Mediana: {mediana:.2f}")
    print(f"  Std:     {std:.2f}")
    print(f"  CV:      {cv:.1f}%")
# 3. Assimetria do colesterol
print(f"Assimetria chol: {df['chol'].skew():.2f}")
# > 0 → assimetria positiva (cauda direita)

# 4. Outliers com IQR
Q1  = df["chol"].quantile(0.25)
Q3  = df["chol"].quantile(0.75)
IQR = Q3 - Q1
n_out_iqr = df[
    (df["chol"] < Q1-1.5*IQR) |
    (df["chol"] > Q3+1.5*IQR)
].shape[0]
print(f"Outliers IQR: {n_out_iqr}")

# Z-score
z = np.abs(stats.zscore(df["chol"]))
print(f"Outliers Z-score (|z|>3): {(z>3).sum()}")
