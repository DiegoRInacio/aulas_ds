Métricas de Classificação

  • Accuracy = (TP + TN) / Total
  • Precision = TP / (TP + FP) — evitar falsos positivos
  • Recall = TP / (TP + FN) — evitar falsos negativos
  • F1 = 2 × (P × R) / (P + R) — equilíbrio P/R

Métricas de Regressão

  • R² = 1 − SSres/SStot → proporção da variância explicada
  • RMSE = √(Σ(ŷ−y)²/n) → erro na unidade original
  • MAE = Σ|ŷ−y|/n → erro médio absoluto

K-means — Fluxo

  • Inicializa k centróides aleatórios
  • Atribui cada ponto ao centróide mais próximo
  • Recalcula centróides (média dos pontos do cluster)
  • Repete até convergência (inércia mínima)
  • kmeans.inertia_ → soma das distâncias²
  • kmeans.cluster_centers_ → centróides finais

Random Forest — Conceitos

  • N árvores em bootstrap samples (bagging)
  • Cada split: subset aleatório de features
  • Classificação: votação; Regressão: média
  • rf.feature_importances_ → importância de cada feature

Visualização — Quando Usar Cada Gráfico

  • Histograma / Boxplot → distribuição de variável contínua
  • Barras → comparação entre categorias
  • Linha → evolução temporal
  • Dispersão (scatter) → correlação entre duas variáveis
  • Heatmap → correlações entre múltiplas variáveis
  • Pizza → proporções (máx. 5 categorias)
