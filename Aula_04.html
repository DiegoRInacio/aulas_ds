O que é Probabilidade?

Conceito

🎯

Clássica (Laplace)

Casos favoráveis ÷ casos possíveis.
Assume eventos igualmente prováveis.

P(A) = |A| / |Ω|

Ex: dado justo — P(par) = 3/6 = 0,5

🔁

Frequentista

Frequência relativa no limite de infinitas repetições do experimento.

P(A) = lim(nₐ/n)

Ex: taxa de churn observada em 10k clientes

🧠

Bayesiana (Subjetiva)

Grau de crença racional que pode ser atualizado com novas evidências.

P(A|B) ∝ P(B|A)·P(A)

Ex: probabilidade de fraude após novo dado

Fundamentos de Probabilidade

Axiomas e Operações com Eventos

Fundamentos

⚙️ Axiomas de Kolmogorov

  • Não-negatividade: P(A) ≥ 0 para todo evento A
  • Normalização: P(Ω) = 1 — algo sempre acontece
  • Aditividade: se A ∩ B = ∅, então P(A ∪ B) = P(A) + P(B)

🔧 Operações essenciais

OperaçãoNotaçãoFórmula
UniãoA ∪ BP(A)+P(B)−P(A∩B)
InterseçãoA ∩ BP(A)·P(B|A)
ComplementoAᶜ1 − P(A)
CondicionalP(A|B)P(A∩B)/P(B)

💼 Aplicação em negócios

📧 Campanha de e-mail marketing

P(abrir e-mail) = 0,25    P(clicar) = 0,10

P(abrir ou clicar):

P(A∪B) = 0,25 + 0,10 − P(A∩B)

Se clicar implica abrir: P(A∩B) = P(B) = 0,10
→ P(A∪B) = 0,25 + 0,10 − 0,10 = 0,25

🔑 Complemento é poderoso

Às vezes é mais fácil calcular a probabilidade do evento contrário e subtrair de 1.

P(pelo menos 1 venda) = 1 − P(nenhuma venda)

Probabilidade Condicional e Independência

Condicional
P(A|B) = P(A ∩ B) / P(B)
"Probabilidade de A dado que B ocorreu"

🛒 Exemplo: Análise de cesta de compras

De 1000 clientes:

  • 500 compraram produto A
  • 300 compraram produto B
  • 200 compraram ambos (A e B)
P(B|A) = P(A∩B)/P(A) = 0,20/0,50 = 0,40

40% dos clientes que compraram A também compraram B → oportunidade de cross-sell!

🔓 Independência de Eventos

A e B são independentes quando o resultado de um não afeta o outro:

P(A∩B) = P(A) · P(B)
equivalentemente: P(A|B) = P(A)

⚠️ Independência vs. Exclusão Mútua

IndependentesMutuamente exclusivos
DefiniçãoUm não afeta o outroNão podem ocorrer juntos
P(A∩B)P(A)·P(B)0
ExemploDois lançamentos de moedaCara e coroa na mesma moeda

Teorema de Bayes

Bayes
P(A|B) = P(B|A) · P(A) / P(B)
Posterior = Verossimilhança × Prior / Evidência

🔑 Os três ingredientes

  • Prior P(A): nossa crença antes de ver o dado
  • Verossimilhança P(B|A): probabilidade de observar B se A for verdade
  • Posterior P(A|B): crença atualizada após observar B

🚀 Por que Bayes é revolucionário?

Permite atualizar crenças com evidências de forma formal e quantitativa. É a base de sistemas de recomendação, filtros de spam, diagnósticos médicos e modelos de machine learning probabilísticos.

🦠 Exemplo Clássico: Teste Médico

Prevalência da doença: 1% (P(D) = 0,01)
Sensibilidade do teste: 99% (P(+|D) = 0,99)
Especificidade: 95% (P(−|Saudável) = 0,95)

Pergunta: se o teste deu positivo, qual a prob. de ter a doença?

P(+) = P(+|D)·P(D) + P(+|S)·P(S)
= 0,99×0,01 + 0,05×0,99 = 0,0594
P(D|+) = (0,99×0,01)/0,0594 ≈ 16,7%

⚠️ Apesar de 99% de sensibilidade, apenas 16,7% de chance real! A baixa prevalência domina.

Teorema de Bayes em Negócios

Aplicação

💳 Detecção de Fraude

  • P(Fraude) = 0,2% — taxa base
  • P(Alerta|Fraude) = 90% — modelo detecta
  • P(Alerta|Legítima) = 5% — falso positivo
P(Fraude|Alerta) = (0,90 × 0,002) / P(Alerta)
P(Alerta) = 0,90×0,002 + 0,05×0,998 = 0,0508
P(Fraude|Alerta) ≈ 3,5%

Mesmo com boa detecção, a baixa taxa base gera muitos falsos positivos — um problema real em sistemas antifraude.

📧 Filtro de Spam Bayesiano

Palavra "grátis" aparece em:

  • 80% dos spams  → P("grátis"|spam) = 0,80
  • 5% dos e-mails normais → P("grátis"|legítimo) = 0,05
  • 40% das mensagens são spam → P(spam) = 0,40
P(spam|"grátis") = (0,80×0,40) / [(0,80×0,40)+(0,05×0,60)]
= 0,32 / 0,35 ≈ 91,4%

📌 Regra de ouro

O resultado bayesiano é sempre sensível ao prior. Em negócios, escolha o prior com base em dados históricos — nunca em intuição pura.

Distribuições de Probabilidade

Variáveis Aleatórias e Valor Esperado

Distribuições

Discreta

Assume valores contáveis.
Ex: nº de vendas, defeitos, cliques

Contínua

Assume qualquer valor num intervalo.
Ex: tempo, preço, peso, altura

E[X] = Σ xᵢ · P(X = xᵢ)
Valor Esperado (média ponderada pelas probabilidades)

💰 Valor Esperado em Decisões

🎰 Exemplo: Lançamento de Produto

CenárioLucroPE[X] parcial
SucessoR$500k0,40R$200k
ModeradoR$100k0,35R$35k
Fracasso−R$200k0,25−R$50k
Total1,00R$185k

E[X] = R$185k → lançar o produto tem valor esperado positivo ✅

⚠️ Valor esperado ≠ resultado garantido

Um E[X] positivo justifica a decisão no longo prazo — mas numa decisão única, a empresa pode perder R$200k. Risco e variância também importam.

Distribuição Binomial

Binomial
P(X=k) = C(n,k) · pᵏ · (1−p)ⁿ⁻ᵏ
n = tentativas  |  k = sucessos  |  p = prob. de sucesso

✅ Quando usar Binomial?

  • Número fixo de tentativas (n)
  • Cada tentativa é independente
  • Apenas dois resultados: sucesso/fracasso
  • Probabilidade de sucesso constante (p)

📊 Média e Variância

μ = n·p     σ² = n·p·(1−p)

💼 Aplicações em Negócios

📧 Taxa de conversão

10 leads qualificados, taxa de fechamento = 30%.
Qual a P(fechar exatamente 3)?

P(X=3) = C(10,3)·0,3³·0,7⁷ ≈ 26,7%

🏭 Controle de Qualidade

Lote de 20 peças, taxa de defeito = 5%.
P(zero defeitos)?

P(X=0) = 0,95²⁰ ≈ 35,8%

📉 Risco de Churn

100 clientes, P(churn mensal) = 2%.
E[clientes que saem] = 100 × 0,02 = 2 clientes/mês

Distribuição de Poisson

Poisson
P(X=k) = (e⁻λ · λᵏ) / k!
λ = taxa média de ocorrência no intervalo

✅ Quando usar Poisson?

  • Contagem de eventos em intervalo fixo (tempo ou espaço)
  • Eventos ocorrem de forma independente
  • Taxa média λ é constante
  • Dois eventos não ocorrem simultaneamente

📊 Média e Variância

μ = λ     σ² = λ
Média = Variância = λ

💼 Aplicações em Negócios

📞 Central de Atendimento

Em média 8 chamadas/hora (λ=8).
P(receber exatamente 10 chamadas)?

P(X=10) = (e⁻⁸·8¹⁰)/10! ≈ 9,9%

Dimensionamento de equipe: P(X > 12) = quanto seria necessário para atender 95% das demandas?

🛒 Demanda de Estoque

Produto vendido em média 5 unidades/dia (λ=5).
P(vender 0 unidades) = e⁻⁵ ≈ 0,67%
P(vender mais de 8) — risco de ruptura de estoque.

🔗 Poisson como limite da Binomial

Quando n → ∞ e p → 0 com λ = n·p constante, Binomial(n,p) → Poisson(λ). Útil quando n é muito grande e p muito pequeno (fraudes, acidentes).

Distribuição Normal em Negócios

Normal

📐 Z-score e tabela normal

🏭 Controle de Processo — SPC

Tempo de entrega: μ = 5 dias, σ = 1,2 dias

Pergunta: qual a P(entrega em até 7 dias)?

Z = (7 − 5) / 1,2 = 1,67
P(X ≤ 7) = Φ(1,67) ≈ 95,2%

→ 95,2% das entregas chegam em até 7 dias. Pode-se prometer esse prazo com alta confiança.

💰 VaR — Value at Risk

Perda máxima esperada com 95% de confiança. Ex: portfólio com retorno médio 2% e σ=5%:

VaR₉₅ = μ − 1,645 · σ = 2 − 8,2 = −6,2%

🎯 Aplicações práticas

P(≤ μ−2σ)
2,3%
P(≤ μ−σ)
15,9%
P(≤ μ)
50,0%
P(≤ μ+σ)
84,1%
P(≤ μ+2σ)
97,7%

📦 Estoque de segurança

Demanda diária: μ=100, σ=15. Para garantir 99% de disponibilidade:
Estoque = μ + 2,33·σ = 100 + 34,95 ≈ 135 unidades

Probabilidade com Python — SciPy

Python
from scipy import stats
import numpy as np

# ── BINOMIAL ──
n, p = 10, 0.30
binom = stats.binom(n, p)

print(binom.pmf(3))     # P(X=3) ≈ 0,267
print(binom.cdf(3))     # P(X≤3)
print(1 - binom.cdf(5)) # P(X>5)
print(binom.mean(), binom.std()) # μ, σ

# ── POISSON ──
lam = 8  # média 8 chamadas/hora
pois = stats.poisson(lam)

print(pois.pmf(10))    # P(X=10) ≈ 0,099
print(pois.cdf(12))    # P(X≤12)
print(1-pois.cdf(12))  # P(X>12) = risco de sobrecarga

# ── NORMAL ──
mu, sigma = 5, 1.2  # tempo de entrega
norm = stats.norm(mu, sigma)

print(norm.cdf(7))     # P(X≤7) ≈ 0,952
print(norm.ppf(0.99))  # prazo para 99% das entregas
print(norm.interval(0.95)) # intervalo com 95%
import matplotlib.pyplot as plt
import seaborn as sns

# ── Visualizar Binomial ──
k = np.arange(0, 11)
probs = stats.binom.pmf(k, 10, 0.30)

fig, ax = plt.subplots()
ax.bar(k, probs, color="#0e7490", edgecolor="none")
ax.set_title("Binomial(n=10, p=0.30)")
ax.set_xlabel("Sucessos (k)")
ax.set_ylabel("P(X=k)")
plt.show()

# ── Teorema de Bayes com Python ──
def bayes(prior, likelihood, likelihood_neg):
    """Calcula posterior via Teorema de Bayes."""
    evidencia = (likelihood * prior +
                 likelihood_neg * (1 - prior))
    return (likelihood * prior) / evidencia

# Fraude: prior=0.002, P(alerta|fraude)=0.9, P(alerta|legit)=0.05
post = bayes(0.002, 0.90, 0.05)
print(f"P(Fraude|Alerta) = {post:.1%}")  # 3.5%

Simulação de Monte Carlo

Monte Carlo

🎲 O que é Monte Carlo?

Técnica que usa amostragem aleatória repetida para estimar resultados de problemas complexos. Em vez de calcular analiticamente, simula milhares de cenários e observa a distribuição dos resultados.

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)
N = 100_000  # simulações

# Projeção de receita — 3 variáveis incertas
preco    = np.random.normal(100, 15, N)   # μ=100, σ=15
volume   = np.random.normal(500, 80, N)   # μ=500, σ=80
custo    = np.random.normal(40,  8,  N)   # μ=40,  σ=8

lucro = (preco - custo) * volume

print(f"Lucro médio:   R${lucro.mean():,.0f}")
print(f"Desvio padrão: R${lucro.std():,.0f}")
print(f"P(lucro < 0):  {(lucro < 0).mean():.1%}")
print(f"VaR 95%:       R${np.percentile(lucro, 5):,.0f}")

# Histograma do lucro simulado
plt.hist(lucro, bins=80, color="#0e7490",
         edgecolor="none", density=True)
plt.axvline(np.percentile(lucro,5), color="#e84a2f",
            ls="--", label="VaR 95%")
plt.title("Distribuição do Lucro — Monte Carlo")
plt.legend()
plt.show()

💼 Usos de Monte Carlo em negócios

📈 Projeção Financeira

Simular receita considerando incerteza em preço, volume e custos — gera um intervalo de confiança para o orçamento.

📦 Gestão de Estoque

Simular demanda variável para calcular o nível ideal de estoque de segurança, minimizando custo de ruptura e excesso.

🏗️ Gestão de Projetos

Simular duração de cada tarefa para estimar a distribuição do prazo total do projeto (PERT probabilístico).

💳 Risco de Crédito

Simular inadimplência de uma carteira de empréstimos para estimar perdas esperadas e inesperadas.

from scipy import stats
import numpy as np

# 1. Probabilidade clássica
p_inad     = 60 / 500
p_adim_ra = 180 / 220
print(f"P(inadimplente):          {p_inad:.1%}")
print(f"P(adimplente|renda alta): {p_adim_ra:.1%}")

# 2. Binomial
binom = stats.binom(20, 0.12)
print(f"\nP(X=2):   {binom.pmf(2):.4f}")
print(f"P(X>4):   {1 - binom.cdf(4):.4f}")
print(f"E[X]:     {binom.mean():.2f} inadimplentes esperados")

# 3. Poisson
pois = stats.poisson(3)
print(f"\nP(X=0):   {pois.pmf(0):.4f}")
print(f"P(X>6):   {1 - pois.cdf(6):.4f}")

# 4. Normal — score de crédito
norm = stats.norm(650, 80)
print(f"\nP(score>700):  {1 - norm.cdf(700):.4f}")
print(f"Top 10% score: {norm.ppf(0.90):.0f} pontos")
# 5. Teorema de Bayes — fraude
prior      = 0.005
sens       = 0.92
falso_pos  = 0.04

evidencia = sens*prior + falso_pos*(1-prior)
posterior = (sens * prior) / evidencia
print(f"P(fraude|alerta) = {posterior:.2%}")

# 6. Monte Carlo — inadimplência
np.random.seed(42)
N = 50_000
simulacoes = np.random.binomial(500, 0.12, N)

print(f"\nMedia simulada:  {simulacoes.mean():.1f}")
print(f"Desvio padrão:   {simulacoes.std():.1f}")
print(f"VaR 95% (pior 5%): {np.percentile(simulacoes, 95):.0f} inadimplentes")

# 7. Plot das três distribuições
import matplotlib.pyplot as plt
fig, axes = plt.subplots(1, 3, figsize=(14, 4))

# Binomial
k = np.arange(0,8)
axes[0].bar(k, stats.binom.pmf(k,20,0.12), color="#0e7490")
axes[0].set_title("Binomial(20, 0.12)")

# Poisson
k2 = np.arange(0,12)
axes[1].bar(k2, stats.poisson.pmf(k2,3), color="#d97706")
axes[1].set_title("Poisson(λ=3)")

# Monte Carlo
axes[2].hist(simulacoes, bins=40, color="#16a34a", edgecolor="none")

plt.tight_layout()
