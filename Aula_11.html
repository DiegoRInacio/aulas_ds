Algoritmos de Classificação Supervisionada

KNN — K-Nearest Neighbors

Algoritmo

Como funciona?

Para classificar um ponto novo, o KNN:

  1. Calcula a distância desse ponto para todos os pontos de treino
  2. Seleciona os K vizinhos mais próximos
  3. Atribui a classe mais frequente entre esses K vizinhos (votação majoritária)
d(p, q) = √(Σᵢ (pᵢ − qᵢ)²)
Distância Euclidiana — a mais comum no KNN

Como escolher K?

  • K pequeno (1–3): fronteira irregular, overfitting
  • K grande: fronteira suave, underfitting
  • Prática: use CV para testar vários valores de K e escolher pelo F1 ou AUC
  • Geralmente testa-se K = 3, 5, 7, 9, 11...

KNN é "preguiçoso" (lazy learner)

O KNN não constrói um modelo explícito durante o treino — ele simplesmente memoriza todos os dados. A classificação acontece na predição, quando calcula distâncias.


Vantagem: simples, sem hipóteses sobre a distribuição dos dados, atualiza automaticamente com novos dados.


Desvantagem: lento para predição em bases grandes (calcula todas as distâncias), sensível à escala (sempre padronize!) e a ruído.

Cuidado: KNN exige padronização!

Preditores em escalas diferentes distorcem as distâncias. Uma variável em km domina outra em graus. Use sempre StandardScaler antes do KNN.

Árvore de Decisão — Decision Tree

Algoritmo

Como funciona?

A árvore divide os dados recursivamente com perguntas binárias ("Valor > X?") até separar as classes. Cada divisão é escolhida para maximizar a pureza dos grupos.


Critério de impureza:

Gini = 1 − Σ pᵢ²
Gini = 0 → nó puro | Gini = 0,5 → nó totalmente misto
Freq. ≥ 75%?
Nota ≥ 6?

Reprovado

Vantagens e limitações

  • Interpretável: as regras são visíveis e explicáveis
  • Não precisa de padronização (não usa distância)
  • Lida com variáveis mistas (numéricas e categóricas)
  • Tendência ao overfitting se não restrita (use max_depth, min_samples_leaf)
  • Sensível a pequenas variações nos dados de treino

Parâmetros de controle (hiperparâmetros)

ParâmetroEfeito
max_depthProfundidade máxima — controla complexidade
min_samples_leafMínimo de amostras numa folha — evita overfitting
min_samples_splitMínimo para dividir um nó
criterion'gini' (padrão) ou 'entropy'

Random Forest — Ensemble de Árvores

Algoritmo

Ideia central: "a força do conjunto"

Random Forest treina centenas de árvores de decisão, cada uma sobre uma amostra diferente dos dados (bootstrap) e com um subconjunto aleatório de preditores. A previsão final é a votação majoritária de todas as árvores.

ŷ = moda( T₁(x), T₂(x), …, Tₙ(x) )
n árvores votam — ganha a classe mais frequente

Por que é mais robusto que uma árvore só?

  • Cada árvore vê dados levemente diferentes → diversidade
  • Erros individuais se cancelam quando agregados
  • Muito mais resistente a overfitting
  • Fornece importância de variáveis naturalmente

Random Forest na prática

n_estimators: número de árvores. Mais é melhor até certo ponto (100–500 são valores típicos).


max_features: número de preditores considerados em cada divisão. Padrão: √n_features para classificação.


feature_importances_: o atributo mais valioso do RF — diz quais variáveis mais contribuem para as previsões.

Limitação principal

Interpretabilidade: centenas de árvores formam uma "caixa-preta". É preciso usar ferramentas como SHAP ou importância de variáveis para explicar o que o modelo aprendeu.

SVM — Máquina de Vetor de Suporte

Algoritmo

Ideia central: fronteira de máxima margem

O SVM encontra o hiperplano que separa as classes com a maior margem possível. Os pontos mais próximos desse hiperplano são chamados de vetores de suporte — são eles que definem a fronteira.

margem = 2 / ‖w‖
Maximizar a margem = minimizar ‖w‖ (norma dos pesos)

Kernel Trick

Quando as classes não são linearmente separáveis, o SVM usa funções kernel para mapear os dados para um espaço de maior dimensão onde a separação é possível.

  • kernel='linear' — separação por linha/plano
  • kernel='rbf' — fronteiras curvas (mais comum)
  • kernel='poly' — fronteiras polinomiais

Hiperparâmetros-chave do SVM

ParâmetroSignificado
CPenalidade por erro. C alto → menos erros, margem menor (mais overfitting). C baixo → margem maior, mais tolerante a erros.
gammaAlcance do kernel RBF. Alto → fronteira irregular (overfitting). Baixo → fronteira suave.
kernelTipo de transformação (linear, rbf, poly)

Quando usar SVM?

  • Dados com muitas features e poucas amostras
  • Problemas de classificação binária bem definidos
  • Quando a interpretabilidade não é prioridade
  • Lento em datasets muito grandes (>100k amostras)

Comparativo — Qual Algoritmo Usar?

Guia Prático
Algoritmo Interpretabilidade Escalabilidade Padronização? Overfitting Melhor quando...
KNN Alta (intuitivo) Baixa (lento) Obrigatória K pequeno → alto Poucos dados, fronteira não-linear simples
Árvore Muito alta (regras) Boa Não necessária Alta sem poda Explicabilidade é essencial (ex.: área jurídica)
Random Forest Média (caixa-preta) Muito boa Não necessária Baixa por natureza Caso geral — robusto e preciso
SVM (RBF) Baixa Média (lento >100k) Obrigatória Depende do C/gamma Dados de alta dimensionalidade (texto, imagem)

Regra prática para começar

Comece sempre com Random Forest como baseline. É robusto, funciona bem "fora da caixa" e fornece importância de variáveis. Se precisar de interpretabilidade, use Árvore. Se o dataset for muito pequeno (<500 amostras), tente KNN. Use SVM para problemas de alta dimensionalidade.

Código — Comparando os 4 Algoritmos

Na Prática
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.svm import SVC
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.metrics import classification_report

# Configuração dos modelos (com Pipeline)
modelos = {
    'KNN (k=7)': Pipeline([
        ('scaler', StandardScaler()),
        ('clf', KNeighborsClassifier(n_neighbors=7))
    ]),
    'Árvore (max_depth=5)': Pipeline([
        ('clf', DecisionTreeClassifier(max_depth=5,
                                        random_state=42))
    ]),
    'Random Forest': Pipeline([
        ('clf', RandomForestClassifier(n_estimators=200,
                                        random_state=42))
    ]),
    'SVM (RBF)': Pipeline([
        ('scaler', StandardScaler()),
        ('clf', SVC(kernel='rbf', probability=True,
                    random_state=42))
    ]),
}

# Comparativo via CV 5-fold
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
resultados = {}

for nome, pipe in modelos.items():
    scores = cross_val_score(pipe, X_train, y_train,
                              cv=cv, scoring='f1_weighted')
    resultados[nome] = scores
    print(f'{nome:30s} F1 = {scores.mean():.4f} '
          f'± {scores.std():.4f}')

Por que usar Pipeline?

  • Garante que o scaler só vê dados de treino em cada fold
  • Evita data leakage — vazamento de informação do teste para o treino
  • Simplifica a implantação: um único objeto para transformar e prever
  • Compatible com GridSearchCV e cross_val_score

O que é Data Leakage?

Se você padroniza antes de dividir os dados, a média e o desvio-padrão calculados incluem informação do conjunto de teste. O modelo "vê" o futuro durante o treino — e o resultado parece melhor do que é na realidade.


❌ Errado: scaler.fit(X) → split
✅ Certo: split → Pipeline(scaler + model)

Clusterização — Agrupando sem Rótulos

Conceito

O que é clusterização?

Algoritmo que agrupa pontos de dados similares em clusters, sem usar rótulos. O modelo descobre a estrutura oculta dos dados por conta própria.


Princípio: pontos dentro do mesmo cluster devem ser similares entre si e diferentes dos outros clusters.

Aplicações reais

  • Segmentação de clientes: agrupar por comportamento de compra
  • Genômica: agrupar genes com expressão similar
  • Compressão de imagens: agrupar cores similares
  • Detecção de anomalias: pontos fora de qualquer cluster
  • Recomendação: agrupar usuários por preferências

Como avaliar clusters sem rótulos?

Silhouette Score: mede quão bem cada ponto está no seu cluster em relação aos outros. Varia de −1 a +1.


silhouette ≈ +1 → cluster compacto e bem separado
silhouette ≈ 0 → ponto na fronteira entre clusters
silhouette ≈ −1 → ponto provavelmente no cluster errado

Inércia (WCSS)

Soma das distâncias quadráticas de cada ponto ao centróide do seu cluster. Mede a compactação interna. Menor é melhor — mas cuidado: sempre decresce com mais clusters.

WCSS = Σₖ Σᵢ∈Cₖ ‖xᵢ − μₖ‖²

K-Means — Algoritmo Iterativo de Centróides

Algoritmo

Passo a passo do K-Means

  1. Inicializar: posiciona K centróides aleatoriamente (ou com K-Means++)
  2. Atribuir: cada ponto vai para o cluster do centróide mais próximo
  3. Atualizar: recalcula cada centróide como a média dos seus pontos
  4. Repetir os passos 2 e 3 até os centróides não mudarem

Método do Cotovelo (Elbow)

Plota a inércia (WCSS) para K = 1, 2, ..., 10. O ponto onde a queda desacelera (o "cotovelo") indica o K ideal.

inercias = []
for k in range(1, 11):
    km = KMeans(n_clusters=k, random_state=42)
    km.fit(X)
    inercias.append(km.inertia_)
plt.plot(range(1,11), inercias, 'o-')
plt.xlabel('K')
plt.ylabel('Inércia (WCSS)')

Limitações do K-Means

  • Precisa definir K com antecedência
  • Assume clusters esféricos e de tamanho similar
  • Sensível a outliers (centróide é a média)
  • Resultado varia com a inicialização aleatória (use n_init=10)
  • Não identifica clusters de formato irregular

K-Means++ — inicialização inteligente

Em vez de centróides totalmente aleatórios, o K-Means++ escolhe cada centróide com probabilidade proporcional à distância dos centróides já escolhidos. Resulta em convergência mais rápida e estável.

KMeans(n_clusters=K,
       init='k-means++',  # padrão
       n_init=10,
       random_state=42)

DBSCAN — Clusters de Formato Livre e Ruído

Algoritmo

Density-Based Spatial Clustering of Applications with Noise

O DBSCAN agrupa pontos que estão próximos entre si e tem densidade suficiente. Diferente do K-Means, ele:

  • Não precisa de K definido
  • Encontra clusters de qualquer forma
  • Identifica ruídos/outliers automaticamente (label = −1)
  • Funciona bem em dados geoespaciais

Dois parâmetros

ParâmetroSignificado
epsRaio de vizinhança: dois pontos são vizinhos se d ≤ eps
min_samplesMínimo de vizinhos para um ponto ser "core point"

Core point: tem ≥ min_samples vizinhos no raio eps
Border point: vizinho de um core point, mas não é core
Noise point: não é core nem border → label = −1

K-Means vs DBSCAN

CritérioK-MeansDBSCAN
Precisa de KSimNão
Forma dos clustersEsféricaQualquer
OutliersNão detectaDetecta
EscalabilidadeAltaMédia
ParâmetrosKeps, min_samples

Como escolher eps?

Use o gráfico de distância dos k-vizinhos mais próximos. Calcule para cada ponto a distância ao seu k-ésimo vizinho, ordene crescente e procure o "cotovelo" — esse é um bom candidato para eps.

from sklearn.neighbors import NearestNeighbors

dists, _ = nbrs.kneighbors(X)
dists_sorted = np.sort(dists[:, -1])

Pipeline de Machine Learning — Do Dado ao Modelo

Etapas de um Projeto de ML

Processo
Problemadefinir objetivo e métrica
Dadoscoleta e exploração
Pré-processolimpeza e features
Modelagemtreino e validação
Avaliaçãométricas e diagnóstico
ImplantaçãoAPI ou relatório

1. Definição do problema

  • O que queremos prever? (variável alvo)
  • Qual a métrica de sucesso? (F1, AUC, RMSE...)
  • Classificação ou regressão?
  • Dados disponíveis suficientes?

2–3. Dados e Pré-processamento

  • EDA: histogramas, correlações, outliers
  • Tratar valores faltantes (imputação ou remoção)
  • Codificar categorias (One-Hot, Label Encoding)
  • Padronizar/normalizar variáveis numéricas
  • Engenharia de features: criar novos atributos úteis

4–5. Modelagem e Avaliação

  • Dividir dados: treino / validação / teste
  • Testar múltiplos algoritmos com CV
  • Otimizar hiperparâmetros (GridSearchCV, RandomizedSearch)
  • Avaliar no conjunto de teste (uma única vez!)
  • Análise de erros: onde o modelo erra mais?

Golden rule da avaliação

O conjunto de teste deve ser usado apenas UMA vez — no final. Se você usar o teste para escolher hiperparâmetros, ele contamina a avaliação e o resultado é otimista. Use validação cruzada (CV) para todas as decisões de modelagem.

GridSearchCV — Busca dos Melhores Hiperparâmetros

Técnica

O que são hiperparâmetros?

Configurações do modelo definidas antes do treino (não aprendidas dos dados). Exemplos: K do KNN, max_depth da árvore, n_estimators do Random Forest.


O GridSearchCV testa todas as combinações possíveis de uma grade de valores usando validação cruzada, e retorna a melhor configuração.

from sklearn.model_selection import GridSearchCV

pipe_rf = Pipeline([
    ('clf', RandomForestClassifier(random_state=42))
])

param_grid = {
    'clf__n_estimators': [100, 200, 300],
    'clf__max_depth':    [None, 10, 20],
    'clf__min_samples_leaf': [1, 3, 5],
}

gs = GridSearchCV(
    pipe_rf, param_grid,
    cv=StratifiedKFold(5),
    scoring='f1_weighted',
    n_jobs=-1,   # paraleliza
    verbose=1
)
gs.fit(X_train, y_train)

print('Melhores parâmetros:')
print(gs.best_params_)
print(f'Melhor F1 (CV): {gs.best_score_:.4f}')

GridSearch vs RandomizedSearch

GridSearchCV: testa todas as combinações. Garantido encontrar o melhor da grade, mas pode ser lento com muitos parâmetros.


RandomizedSearchCV: testa N combinações aleatórias da grade. Mais rápido, geralmente encontra resultado quase tão bom. Use quando a grade tiver muitos valores.


Grid: 3×3×3 = 27 combinações × 5 folds = 135 modelos
Randomized(n_iter=20): 20 × 5 = 100 modelos

Dica: n_jobs=-1

O parâmetro n_jobs=-1 usa todos os núcleos da CPU disponíveis para paralelizar os treinos. Em datasets grandes, isso reduz o tempo drasticamente.

Boas práticas do Pipeline ML

  • Sempre use Pipeline para evitar data leakage
  • Padronize antes de KNN e SVM (obrigatório); RF e Árvores não precisam
  • Use StratifiedKFold para dados desbalanceados
  • Avalie com métricas adequadas: AUC para classes desbalanceadas, F1 para equilíbrio
  • Toque no conjunto de teste apenas uma vez
  • Documente todos os hiperparâmetros e versões
