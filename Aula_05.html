Amostragem, erro padrao e intervalos

Estimadores e Intervalos de Confianca

Estimacao

Ideia principal

  • Amostras diferentes geram estimativas diferentes.
  • O erro padrao mede a variabilidade do estimador.
  • Quanto maior `n`, mais precisa tende a ser a estimativa.
EP(x̄) = s / √n
Base para construir intervalos de confianca para a media.

Forma geral

intervalo = estimativa ± margem de erro

Margem de erro = valor critico × erro padrao.

IC95% ≈ x̄ ± 1,96 × EP
Em amostras grandes, o valor 1,96 e uma boa aproximacao.

Exemplo de intervalo e tamanho de amostra

Aplicacao
ParametroValor
Ticket medioR$ 184
Desvio amostralR$ 40
Tamanho da amostra64
EP = 40 / √64 = 5
IC95% ≈ 184 ± 1,96 × 5
IC95% ≈ [174,2 ; 193,8]

Tamanho de amostra para proporcao

n = z² · p · (1 - p) / E²

Para 95% de confianca, erro de 5% e sem estimativa previa, usar `p = 0,5` leva a aproximadamente 385 respostas.

Leitura correta

Mais dados reduzem incerteza aleatoria, mas nao corrigem vies de coleta.

Testes de hipotese, p-valor e risco de decisao

Como funciona um teste de hipotese

Metodo
H₀

Hipotese nula

Assume ausencia de efeito, diferenca ou associacao.

H₁

Hipotese alternativa

Representa o efeito que queremos investigar.

α

Significancia

Limite de tolerancia para falso positivo, geralmente 5%.

Pergunta central

Se H₀ fosse verdadeira, os dados observados seriam plausiveis? Se forem muito improvaveis, rejeitamos H₀.

p-valor, erro tipo I e poder

Interpretacao
⚠️

Erro Tipo I

Rejeitar H₀ quando ela e verdadeira.

🫥

Erro Tipo II

Nao rejeitar H₀ quando ela e falsa.

💪

Poder

Chance de detectar um efeito real: `1 - β`.

📐

p-valor

Probabilidade de observar um resultado tao extremo quanto o obtido, assumindo H₀.

se p ≤ α, rejeitamos H₀
p-valor nao mede relevancia pratica e nao e a probabilidade de H₀ ser verdadeira.

Python: intervalos e testes

Codigo
import numpy as np
from scipy import stats

ticket = np.array([175, 168, 190, 201, 185, 178, 194, 183, 176, 188])
media = ticket.mean()
desvio = ticket.std(ddof=1)
n = len(ticket)

ic = stats.t.interval(
    confidence=0.95,
    df=n-1,
    loc=media,
    scale=desvio / np.sqrt(n)
)

print(media, ic)
import numpy as np
from statsmodels.stats.proportion import proportions_ztest

conversoes = np.array([320, 377])
usuarios = np.array([4000, 4100])

z_stat, p_valor = proportions_ztest(conversoes, usuarios)
print(f"z = {z_stat:.3f}")
print(f"p = {p_valor:.4f}")
