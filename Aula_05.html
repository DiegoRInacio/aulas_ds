Estimadores e Intervalos de Confianca

Estimacao

Ideia principal

  • Amostras diferentes geram estimativas diferentes.
  • O erro padrao mede a variabilidade do estimador.
  • Quanto maior n, mais precisa tende a ser a estimativa.
EP(x̄) = s / √n
Base para construir intervalos de confianca para a media.

Exemplo rapido

s = 20, n = 100 → EP = 2,0
s = 20, n = 400 → EP = 1,0
Quadruplicar n reduz EP pela metade.

Forma geral do IC

intervalo = estimativa ± margem de erro

Margem de erro = valor critico × erro padrao.

IC95% ≈ x̄ ± 1,96 × EP
Em amostras grandes, o valor 1,96 e uma boa aproximacao para 95%.

Tamanho de amostra para proporcao

n = z² · p · (1 - p) / E²

Para 95% de confianca, erro de 5% e sem estimativa previa, usar p = 0,5 leva a aproximadamente 385 respostas.

Leitura correta

Mais dados reduzem incerteza aleatoria, mas nao corrigem vies de coleta.

Cuidado com a interpretacao

O IC de 95% NAO significa "95% de chance de p estar no intervalo." Significa que 95% dos intervalos construidos por esse metodo conterao o verdadeiro p.

Testes de hipotese, p-valor e risco de decisao

Como Funciona um Teste de Hipotese

Metodo
H₀

Hipotese nula

Assume ausencia de efeito, diferenca ou associacao. Ex: o novo botao NAO muda a taxa de conversao.

H₁

Hipotese alternativa

Representa o efeito que queremos investigar. Ex: o novo botao AUMENTA a taxa de conversao.

α

Significancia

Limite de tolerancia para falso positivo, geralmente 5%. Definir ANTES de coletar dados.

Pergunta central

Se H₀ fosse verdadeira, os dados observados seriam plausiveis? Se forem muito improvaveis (p < α), rejeitamos H₀.

Passos do teste

  1. Formular H₀ e H₁ antes de ver os dados.
  2. Escolher nivel de significancia α (tipicamente 5%).
  3. Calcular a estatistica do teste e o p-valor.
  4. Decidir: rejeitar ou nao rejeitar H₀.

p-valor, Erro Tipo I e Poder

Interpretacao
⚠️

Erro Tipo I (α)

Rejeitar H₀ quando ela e verdadeira. Falso positivo. Controlado por α = 5%.

🫥

Erro Tipo II (β)

Nao rejeitar H₀ quando ela e falsa. Falso negativo. Tipicamente β = 20%.

💪

Poder (1 − β)

Chance de detectar um efeito real. Meta: 80%. Cresce com n e com o tamanho do efeito.

📐

p-valor

Probabilidade de observar resultado tao extremo quanto o obtido, assumindo H₀ verdadeira.

se p ≤ α → rejeitamos H₀
p-valor nao mede relevancia pratica nem e a probabilidade de H₀ ser verdadeira.
DecisaoH₀ VerdadeiraH₀ Falsa
Rejeitar H₀Erro Tipo I — αCorreto — Poder (1−β)
Nao rejeitar H₀Correto — (1−α)Erro Tipo II — β

Significancia Estatistica ≠ Relevancia Pratica

Atencao
⚡

Caso real

Com n = 50.000 por grupo, uma diferenca de 0,3 segundos no tempo de carregamento pode ter p < 0,001. Mas vale o investimento de refatorar toda a infra?

d de Cohen = (μ₁ − μ₂) / s_pooled
Mede o tamanho do efeito em desvios-padrao
d de CohenInterpretacao
0,2Efeito pequeno
0,5Efeito medio
0,8+Efeito grande
from scipy import stats
import numpy as np

np.random.seed(0)
g1 = np.random.normal(10.0, 2.0, 50_000)
g2 = np.random.normal(10.3, 2.0, 50_000)

t, p = stats.ttest_ind(g1, g2)

# Cohen's d
s_pool = np.std(np.concatenate([g1, g2]), ddof=1)
d = (g1.mean() - g2.mean()) / s_pool

print(f"p-valor:    {p:.4f}")   # 0.0000 (sig.)
print(f"Cohen's d:  {d:.3f}")   # -0.152 (pequeno!)
print(f"Diferenca:  {g1.mean()-g2.mean():.2f}")  # -0.30

Conclusao

Reporte SEMPRE o tamanho do efeito junto ao p-valor. Um p pequeno com amostra grande nao garante relevancia pratica.

Meta padrao

Poder ≥ 80% com α = 5%. Para efeitos pequenos (d = 0,2), sao necessarios ~393 por grupo.

from statsmodels.stats.power import TTestIndPower

analise = TTestIndPower()

# Quantos por grupo para 80% de poder?
n = analise.solve_power(
    effect_size=0.5,   # Cohen's d medio
    alpha=0.05,
    power=0.80,
    alternative='two-sided'
)
print(f"n por grupo: {n:.0f}")  # → 64

# Qual e o poder com n=50 e d=0.3?
p = analise.power(
    effect_size=0.3,
    nobs1=50,
    alpha=0.05
)
print(f"Poder: {p:.1%}")  # → 24,1% (baixo!)

Requisitos para t e ANOVA

Normalidade da distribuicao (ou n grande pelo TCL) e independencia entre observacoes. Para dados ordinais ou amostras pequenas sem normalidade, considere testes nao-parametricos (Mann-Whitney, Kruskal-Wallis).

Python: Teste t de Duas Amostras

Codigo

Cenario

Comparar o tempo de atendimento de duas equipes: A (40 chamadas) e B (42 chamadas). O novo processo (B) e mais rapido?

from scipy import stats
import numpy as np

np.random.seed(42)
equipe_a = np.random.normal(9.2, 1.8, 40)
equipe_b = np.random.normal(8.5, 2.1, 42)

# 1. Verificar igualdade de variancias (Levene)
_, p_lev = stats.levene(equipe_a, equipe_b)
equal_var = p_lev > 0.05
print(f"Variancias iguais? {equal_var}")

# 2. Teste t (Welch se variancias diferentes)
t, p = stats.ttest_ind(equipe_a, equipe_b,
                        equal_var=equal_var)
print(f"t = {t:.3f}, p = {p:.4f}")
print("Rejeitar H0?", "Sim" if p < 0.05 else "Nao")

# 3. Cohen's d
s = np.std(np.concatenate([equipe_a, equipe_b]), ddof=1)
d = (equipe_a.mean() - equipe_b.mean()) / s
print(f"Cohen's d = {d:.3f}")

Saida esperada

t ≈ 1.87, p ≈ 0.065
→ Nao rejeita H₀ ao nivel 5%
→ Cohen's d ≈ 0.38 (efeito pequeno-medio)

t pareado (antes/depois)

np.random.seed(1)
antes = np.random.normal(10, 2, 30)
depois = antes - np.random.normal(1, 0.5, 30)

t, p = stats.ttest_rel(antes, depois)
print(f"t = {t:.3f}, p = {p:.4f}")
# Mesmo individuo nos dois momentos
# p tipicamente < 0.001

Python: Intervalos e Teste A/B

Codigo
import numpy as np
from scipy import stats

# IC para media com distribuicao t
ticket = np.array([175, 168, 190, 201, 185,
                   178, 194, 183, 176, 188])
media = ticket.mean()
desvio = ticket.std(ddof=1)
n = len(ticket)

ic = stats.t.interval(
    confidence=0.95,
    df=n - 1,
    loc=media,
    scale=desvio / np.sqrt(n)
)

print(f"Media: {media:.1f}")
print(f"IC 95%: [{ic[0]:.1f}, {ic[1]:.1f}]")
import numpy as np
from statsmodels.stats.proportion import proportions_ztest

# Teste A/B de proporcoes
conversoes = np.array([320, 377])
usuarios   = np.array([4000, 4100])

z_stat, p_valor = proportions_ztest(
    conversoes, usuarios, alternative='smaller'
)
print(f"z = {z_stat:.3f}")
print(f"p = {p_valor:.4f}")

# Intervalo para cada proporcao
from statsmodels.stats.proportion import proportion_confint
for conv, n in zip(conversoes, usuarios):
    ic = proportion_confint(conv, n, alpha=0.05)
    print(f"{conv/n:.3f}  IC=[{ic[0]:.3f},{ic[1]:.3f}]")

Python: ANOVA Unidirecional

Codigo

Cenario

Receita media por canal: Email, App e Loja Fisica. Ha diferenca significativa entre os canais?

from scipy import stats
import numpy as np

np.random.seed(7)
email = np.random.normal(320, 60, 50)
app   = np.random.normal(380, 75, 50)
loja  = np.random.normal(290, 55, 50)

# ANOVA one-way
F, p = stats.f_oneway(email, app, loja)
print(f"F = {F:.2f}, p = {p:.4f}")
# F = 14.21, p = 0.0000 → rejeita H₀

# Post-hoc: Tukey HSD
from statsmodels.stats.multicomp import pairwise_tukeyhsd
import numpy as np

dados  = np.concatenate([email, app, loja])
grupos = ['Email']*50 + ['App']*50 + ['Loja']*50
resultado = pairwise_tukeyhsd(dados, grupos)
print(resultado)
ComparacaoDiferencap-adjSig.?
App − Email+R$600,001Sim
Email − Loja+R$300,040Sim
App − Loja+R$900,000Sim

Pos-hoc e obrigatorio

A ANOVA so diz que HA diferenca entre grupos. Tukey HSD identifica QUAIS pares diferem, controlando o erro acumulado por multiplos testes.

Conclusao de negocio

App gera R$60 a mais que Email e R$90 a mais que Loja — considerar realocar orcamento para o canal App.

from scipy import stats
import numpy as np

tabela = np.array([
    [210, 90],   # Email
    [180, 70],   # Redes Sociais
    [160, 90],   # Organico
])

chi2, p, gl, esperado = stats.chi2_contingency(tabela)
print(f"chi2 = {chi2:.3f}")
print(f"p    = {p:.4f}")
print(f"gl   = {gl}")
# chi2 = 6.42, p = 0.040, gl = 2

# Residuos padronizados (quem contribui mais?)
obs = tabela.astype(float)
res = (obs - esperado) / np.sqrt(esperado)
print("Residuos padronizados:")
print(res.round(2))

Interpretacao

p = 0,040 < 0,05 → canal e churn NAO sao independentes. Clientes organicos churnam mais. Investigar onboarding para esse perfil.

Armadilhas Comuns em Testes

Atencao
🎣

p-hacking

Testar multiplas variacoes ate encontrar p < 0,05. Com 20 testes independentes, espera-se 1 falso positivo por acaso puro.

Solucao: pre-registrar hipoteses e usar correcao de Bonferroni (α / k).

👀

Peeking

Encerrar o experimento assim que p cruzar 0,05. Inflaciona a taxa de falso positivo para ate 30%.

Solucao: definir n antes de iniciar e esperar o fim planejado (ou usar testes sequenciais).

🔀

HARKing

Hipoteses formuladas apos ver os dados (Hypothesizing After Results Known). Transforma exploracao em confirmacao.

Solucao: separar claramente analise exploratoria de confirmatoria.

Bonferroni: α* = α / k
Para 5 testes simultaneos com α = 5%, use α* = 1% em cada teste individual

Outras precaucoes

Contaminacao de grupos (um usuario ver as duas variacoes), efeito de novidade (usuarios respondem diferente so por ser novo) e sazonalidade nao controlada podem invalidar resultados mesmo sem intencao.
